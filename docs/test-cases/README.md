# Описание тестов для приложения HandyFix

## Обзор

В проекте HandyFix создано **32 теста**, которые покрывают основные функциональные области приложения. Тесты разделены на два типа:

1. **Unit тесты** (22 теста) - тестирование моделей и их связей
2. **Feature тесты** (10 тестов) - тестирование контроллеров и функциональности приложения

## Типы тестирования

### Unit тесты (Модели)
Проверяют корректность работы моделей данных и их связей:
- Отношения между моделями (belongsTo, hasMany, hasOne)
- Аксессоры и мутаторы
- Бизнес-логику моделей

### Feature тесты (Контроллеры)
Проверяют функциональность приложения на уровне HTTP-запросов:
- Доступность маршрутов
- Авторизацию и права доступа
- CRUD операции (создание, чтение, обновление, удаление)
- Валидацию данных
- Редиректы и сообщения

## Запуск тестов

```bash
# Запуск всех тестов
php artisan test

# Запуск только Unit тестов
php artisan test --testsuite=Unit

# Запуск только Feature тестов
php artisan test --testsuite=Feature

# Запуск конкретного теста
php artisan test --filter test_name
```
